# 📦 AppCrate

**AppCrate** est un utilitaire léger pour Windows permettant d'isoler l'exécution d'une application dans un dossier restreint ou un bac à sable (sandbox) configurable. Il intègre désormais un sélecteur multilingue directement dans son interface exécutable.

## 🇫🇷 Français

### Description
AppCrate vous permet de lancer un programme exécutable en lui attribuant un répertoire de travail isolé pour empêcher la modification de vos fichiers système ou l'accès non autorisé à d'autres répertoires.

### Fonctionnalités
* 🛡️ **Isolation de dossier** : Restreint l'accès aux fichiers au dossier spécifié.
* 🌐 **Sélecteur de langue intégré** : Changez dynamiquement la langue du logiciel (FR, EN, ES, DE, IT, PT) via un menu déroulant.
* ⚡ **Léger & Rapide** : Compilé directement en C#/.NET sans dépendances lourdes.
* 🛠️ **Build facile** : Compilable en une ligne de commande avec `csc`.

### Compilation
```cmd
csc /target:exe /out:AppCrate.exe /win32manifest:app.manifest AppCrate.cs
```

## 🇬🇧 English

### Description
AppCrate is a lightweight Windows utility designed to isolate application execution within a restricted directory or configurable sandbox. It features built-in multi-language support directly inside the executable UI.

### Features
* 🛡️ **Directory Isolation**: Restricts file access to the designated folder.
* 🌐 **Built-in Language Switcher**: Dynamically change the interface language (FR, EN, ES, DE, IT, PT) from a dropdown menu.
